## 게임 기둥 (불변)

1. **수 vs 질 게이트 긴장** — `DPS = min(머릿수, 사수상한 12) × 화력`. 머릿수는 생존(체력 흡수), 화력은 돌파. 매 게이트 "명백한 오답 없음" 룰. **사수상한 해제류 메커닉 금지**(피버모드 기각 사유).
2. **캐릭터성** — 말랑프렌즈 5종 능력차 + 공용 기계 곰 보스(캐릭터별 색/패턴 1개 변형. 미러 보스 5종 풀제작은 후순위).
3. **초딩 톤** — "고장난 장난감을 멈춘다". 나사·스프링·별 파편, 파스텔. 패배는 장애물 즉사가 아니라 "게이트 선택 실패로 화력이 모자란" 형태가 되도록 배치(gemini).

## 난이도 설계 (M2) — 두 리뷰 합의 반영

- ~~70/50/30~~ → **첫 시도 클리어율 80/65/45** (연박 누적이라 70·50·30이면 전체 10.5%로 과도 — codex P0. gemini도 "30%는 맵다" 동의). 재도전 포함 90/80/65 목표.
- **숨김 어시스트**(같은 스테이지 연속 전멸 시, UI 비표시, 클리어 시 리셋):
  - 1회: 시작 부대 +3 → 2회: +6 (여기까지만 머릿수 — +9는 시작이 사수상한을 넘어 긴장 훼손, codex P0)
  - 3회+: 원인별 보정 — 첫 피격 1회 보호막 + 보스탄 속도 −10% + 장벽 잔여피해 −20% ("이번엔 깰 수 있겠다" 체감형, gemini)
- 스테이지1 = 튜토리얼: 첫 게이트 2개는 둘 다 이득. 게이트 손배치 유지(랜덤 금지).
- **텔레메트리(M1 훅, D1)**: 클리어율만으론 튜닝 불가(codex) — `게이트 선택, 선택 전후 amount/power, 사망 원인, 보스 잔여 HP, assist tier` 로깅. 광장 D1 로깅 인프라 재사용.

## 캐릭터 능력 (M3) — 리뷰 반영 수정안

| 캐릭터 | 능력 (수정) | 리뷰 반영 |
|---|---|---|
| 병아리 | 군집 — **+N 게이트만** 효과 +20% (×N 제외) | ×N 포함 시 첫 게이트에 상한 도달(codex P0) |
| 토끼 | 날쌤 — 조향 +25%, 보스탄 히트박스 −15% + **시각 오라** | 40/20은 보스전 과함(codex), 체감 위해 오라 필수(gemini) |
| 민트 고양이 | 치명 — 데미지 ×1.2 + **사수상한 10** | ×1.3은 상한 구조서 순수 30% 우위(codex P0). 상한↓로 질 정체성 강화 |
| 라떼(강아지) | 든든 — 접촉/탄 피해 −25% + 넉백 저항. **조향 페널티 없음** | 조향 저하는 "렉 걸린 느낌"(gemini C급) → 페널티 삭제 |
| 햄스터 | 보호막 — 스테이지당 1회 피해 무효 + **1.5초** 무적(보스 드레인·게이트 페널티 제외) | 3초는 과함(codex) |

- 부대는 단일 종(대장과 같은 종) 유지. 능력 수치는 M3에서 텔레메트리로 재튜닝 전제.

## 2인 협동 (M5) — codex 보안/동기화 지적 반영

- 같은 트랙 **좌/우 레인 부대 2개**, 각자 드래그 조향. 게이트 레인별 독립쌍("나는 수, 너는 질").
- **하이파이브 게이트**(gemini): 두 부대가 같은 타이밍에 게이트 통과 시 보너스 증폭 — "화면 점유 싸움"을 협동 보상으로 전환.
- **새장 구출**(양 리뷰 최고평가): 한 명 전멸 시 새장 드랍 → 파트너 통과 시 부대 8로 부활.
- 합체 말랑 빔은 v1.5 후보(보류).
- **서버 권위(codex P0)**: relay 모드가 아니라 `worker/src/room.js`의 `SERVER_GAME_MODULES` 모듈로. 서버 책임 = 보스 HP·phase, 새장 소비, 플레이어별 인정 amount/power, 이벤트 시퀀스. 클라는 `boss_damage` 생값 금지 — `gateSeq/amount/power/dt`를 보내고 서버가 스테이지별 최대 DPS로 clamp.
- 알려진 구멍(설계 시 처리): progress drift, 새장 중복 사용, 보스 진입 시점 불일치, reconnect, DO 메모리 초기화, 40msg/s·8KB 제한.
- 구현 난이도 중상 → 별도 마일스톤 유지. **솔로 경로는 코드 분기로 무손상 보존(1인도 됨)**.
