# 말랑 깜짝파티 (surprise-party) — DESIGN/SPEC v0.2

와리오웨어류 **초단위 마이크로게임 러시**. 5초짜리 깜짝 미션이 쉴 새 없이 쏟아지고,
라운드마다 점점 빨라진다. 목숨 3개, 오래 버티는 사람이 승리. 1인 연습 + 2~6인 실시간 경쟁.

- 타깃: 초딩 중심 전연령, 모바일 세로 원터치. 한 판 1~3분.
- 포지셔닝: 라인업의 빈칸인 "웃음 터지는 순발력 파티". 조작 실력보다
  **"뭘 해야 하는지 0.5초 안에 알아채기"**가 승부처라 실력 격차가 작다.

## 1. 재미 기둥 (fun pillars)

1. **순간 파싱의 쾌감** — 매 라운드 두 글자 명령("눌러!", "참아!", "쓸어!")이 갑자기 떨어진다.
2. **규칙 반전 트랩** — "참아!"(누르면 죽음)가 "빨리 해!" 미션들 사이에 섞여 관성을 배신한다.
3. **가속 곡선** — 4라운드마다 "⚡스피드 업!". 초반은 누구나, 후반은 아무도 못 버틴다.
4. **샤덴프로이데** — 같은 시드 = 같은 미션 순서를 동시 플레이. 친구 ❤️가 실시간으로 깎인다.
5. **콤보 스코어** — 같은 라운드까지 버텨도 노미스가 위. "한 번도 안 틀리기" 도전 축.

## 2. 코어 루프 (타이밍 계약)

```
[명령 스플래시]        [미션]                    [결과 플래시]
max(420, 700/speed)ms → baseMs/speed (≥1200ms) → ⭕480ms / ❌650ms → 다음 라운드
                        ↑ 타이머 바 (초록→노랑→빨강 그라데이션)
스피드업 라운드는 스플래시 앞에 "⚡스피드 업!" 750ms 선행.
```

- 체감 라운드 길이: 초반 ~4.5초, ×2.0 구간 ~2.5초. 목숨 3개 소진까지 평균 12~20라운드
  = **한 판 60~120초** (파티 게임 최적 회전율).
- 실패해도 멈추지 않는다 — ❌ 플래시 후 즉시 다음 미션. "아깝다, 한 번 더"의 리듬 유지.

## 3. 난이도 곡선

| 라운드 | speed | 예: 눌러!(3400ms) | 설계 의도 |
|---|---|---|---|
| 1~4 | 1.00 | 3.4초 | 튜토리얼 구간 — 미션 종류 학습 |
| 5~8 | 1.15 | 3.0초 | 리듬 형성 |
| 9~12 | 1.30 | 2.6초 | 첫 사망 다발 구간 |
| 13~16 | 1.45 | 2.3초 | 중수 벽 |
| 17~24 | 1.60~1.90 | ~1.8초 | 고수 구간 |
| 25+ | 2.00 (캡) | 1.7초 | 순수 반응속도 영역 |

속도는 시간 단축 외에 미션 내부 난이도에도 걸린다: 게이지 존 폭 22%/speed,
연타 목표 6+3×speed, 병아리 점프 간격 560/speed ms, 바 왕복 주기 950/speed ms.

## 4. 점수·순위

- 성공: `100 + (콤보-1) × 25`. 실패: 0점, 콤보 리셋, ❤️ -1.
- 순위: **도달 라운드 내림차순 → 점수 내림차순**. 결과 화면에 R값·점수·최고 콤보 병기.
- 솔로 기록: `GameBoot.submitResult({ score: 도달R, points: 점수 })` — resultLabel '도달 라운드'.

(RNG 는 반드시 roundSeed 스트림에서만 소비 — 클라 간 동일 배치 계약 유지.)

### v2 — 변이·아이템

- **반대로 라운드** (R13+, 10% 확률): 보라색 스플래시 "반대로!" — swipe-arrow 는 반대 방향,
  tap-now 는 빨간불에 탭. 대상 미션에 `supportsReverse:true` 플래그.
- **보스 라운드** (R10, R20…): 제한시간 2배·점수 3배의 복합 미션(예: 연타+폭탄 혼합).
- **방해 아이템**: 5콤보 달성 시 1회 충전, 다음 라운드 시작 시 자동 발동 —
  상대 화면 1.2초 흔들기 / 잉크 얼룩 / 타이머 바 숨김 중 랜덤. relay `{t:'item', kind}`.
  단, **판정 자체를 바꾸는 방해 금지**(즉사 유발 금지) — 짜증이 아니라 웃음 유발이 목표.

## 6. 멀티플레이 UX

- **합류**: 방코드 공유(?code=XXXX). 로비에서 별명·캐릭터(공용 초상화 5종) 선택.
- **시작 동기화**: 누구든 "시작!" → `{t:'start'}` 브로드캐스트(멱등). 전원 3-2-1 동시 시작.
  느슨한 동기(계단 레이스 규약) — 라운드 진행은 로컬, 스냅샷으로 상태만 공유.
- **라이벌 스트립**: 상단에 초상화+이름+❤️+R. 사망자는 회색 처리.
- **관전**: 먼저 죽으면 "친구들이 아직 버티는 중 👀" + 스트립 실시간 갱신 + "결과 보기" 스킵.
- **결과**: 전원 사망 시 🥇🥈🥉 랭킹. 내 줄 하이라이트.
- **늦은 합류**: 진행 중 방이면 로비에 힌트 노출, 다음 판부터 합류.
- **재경기(v1.1)**: 결과 화면 "다시 하기" → `{t:'rematch'}` 로 전원 로비 복귀+자동 재시작
  (현재는 reload 로 동일 방 재합류).

## 8. 승격 로드맵

1. **현재**: DRAFT + `stage:'LAB'` — 실험실 카드, 직접 URL.
2. **labMatch**: 실험실 '같이하기' 자동 페어링 — `worldZones LAB_MATCH_CATALOG` +
   `room.js GAME_PATHS` + `world.js GAME_URLS` 등록 필요(관리자 작업, 러너 선례).
3. **정식 부스**: 멀티 실플레이 검증 + 미션 15종+ + 사운드 후 BOOTH_CATALOG 등재.
   ⚠️ 서버 부스 3개째부터 LAB_BOOTH 좌표 충돌 — 배치 조정 필요.

## 9. 밸런싱 계측 (v1.1)

미션별 실패율 로컬 집계(localStorage) → 결과 화면 "제일 약한 미션: 멈춰!" 표기.
전역 밸런싱은 D1 텔레메트리 정착 후: 목표 실패율 R1~4 구간 5~15%, 미션 간 편차 ±10%p 이내.
편차 초과 미션은 baseMs 조정으로 교정.

## 10. 기술 계약 (요약)

- `rush-engine.js` — 순수 코어. **성패가 순서 rng 를 소비하지 않는다**(멀티 공정성 핵심).
  직전 미션 즉시 반복 금지. Node 테스트 `tests/engine.test.mjs`.
- `microgames.js` — `{id, prompt, hint, icon, baseMs, winOnTimeout, mount(ctx)}`.
  `ctx = {root, rng, speed, durationMs, success, fail}`. mount 는 cleanup 함수 반환 가능.
  무작위는 ctx.rng 만. **모듈 1개 = 미션 1개** — 기여자 확장 포인트(공모 후보).
- `multiplayer.js` — MallangRelay 래핑, 판정 불개입. `gameId` 는 `boot.gameId || 'surprise-party'`
  (직접 URL 진입 시 GameBoot.gameId 가 null — 폴백 없으면 릴레이 불능).
- **run 계약 (리뷰 반영)**: 시작 `{t:'start', runId}`(시작자가 생성), 스냅샷 `{t:'snap', runId,
  round, lives, score, alive, name, char}`. **시드 = 방코드 + ':' + runId** — 같은 방 전원 동일
  + 판마다 새 순서(암기 방지). 랭킹·전원사망 감지는 같은 runId 만 집계(늦은 합류자 격리).
  생존 판정 = alive 스냅샷 && 12초 내 수신(네트워크 이탈 blind spot 방지, 관전 중 2초 주기 재평가).
  시작 버튼은 릴레이 합류 완료 전·다른 판 진행 중엔 잠금.
- **입력 공정성 (리뷰 반영)**: 스테이지 캡처 단계에서 비-primary 포인터 차단(멀티터치 연타/
  동시탭 우회 방지). swipe/charge 는 pointercancel 시 판정 없이 리셋. 모듈 mount 예외 =
  무효 라운드(점수·목숨·콤보 불변, 다음 라운드로) — 공짜 성공 금지.
- 서버 무변경(릴레이만), 신규 이미지 에셋 0(이모지+공용 초상화), 무빌드 window 전역.
- 디버그 핸들 `window.__sp` (프리뷰 하니스 전용).
