# 말랑 깜짝파티 (surprise-party) — DESIGN

와리오웨어류 **초단위 마이크로게임 러시**. 5초짜리 깜짝 미션이 쉴 새 없이 쏟아지고,
라운드마다 점점 빨라진다. 목숨 3개, 오래 버티는 사람이 승리. 1인 연습 + 2~6인 실시간 경쟁.

## 재미 기둥 (fun pillars)

1. **순간 파싱의 쾌감** — 매 라운드 "눌러!", "참아!", "쓸어!" 같은 두 글자 명령이 갑자기 떨어진다.
   재미의 핵심은 조작 난이도가 아니라 **"뭘 해야 하는지 0.5초 안에 알아채는 것"**.
2. **규칙 반전 트랩** — "참아!"(누르면 죽음)가 "눌러!" 사이에 섞여 나온다. 관성으로 누르는 순간 빵 터짐.
3. **가속 곡선** — 4라운드마다 "⚡스피드 업!" 연출과 함께 제한시간이 줄어든다. 초반은 누구나,
   후반은 아무도 못 버티는 실력 곡선.
4. **샤덴프로이데** — 멀티에서 모두 **같은 시드 = 같은 미션 순서**를 동시에 플레이. 상단 라이벌
   스트립에 친구의 ❤️가 실시간으로 깎이는 게 보인다. "야 너 죽었지!"가 게임의 절반.
5. **콤보 스코어** — 연속 성공 시 점수 가산 폭증. 생존이 같아도 점수로 순위가 갈린다.

## 구조 (mallang-stairs 규약 계승 — window 전역, 무빌드)

- `rush-engine.js` (`window.SurpriseRushEngine`) — 순수 코어. 시드 결정적 미션 순서·속도 곡선·
  목숨·콤보·점수. DOM/네트워크 무의존 → Node 테스트 가능. 싱글/멀티 공통.
- `microgames.js` (`window.SurpriseMicrogames`) — 마이크로게임 모듈 배열. 각 모듈은
  `{ id, prompt, hint, icon, baseMs, winOnTimeout, mount(ctx) }`. `ctx.rng`(라운드 시드)만 사용해
  내부 배치도 전 클라 동일(공정성). **모듈 하나 추가 = 새 미션** — 기여자 확장 포인트.
- `multiplayer.js` (`window.SurprisePartyMP`) — MallangRelay 래핑, 판정 불개입.
  방코드=공유시드, broadcastStart, 스냅샷(라운드/목숨/점수/생존, 이름/캐릭터 포함).
- `game.js` — 화면(로비/플레이/결과)·라운드 루프·HUD·라이벌 스트립.

서버 무변경(릴레이만) — worker/ 코어와 충돌 없음. 신규 이미지 에셋 0개(이모지 + 공용 초상화).

## 규칙 상세

- 목숨 3, 실패 시 -1, 0이면 탈락. 부활 없음.
- speed = 1 + floor((round-1)/4) × 0.15, 최대 2.0. 제한시간 = baseMs / speed (최소 1200ms).
- 점수 = 성공 시 100 + (콤보-1)×25. 실패 시 콤보 리셋.
- 미션 순서는 시드 결정적, 직전 미션 즉시 반복 금지. 성공/실패는 순서에 영향 없음
  (rng 스트림 분리) → 멀티에서 전원 동일 순서 보장.
- 멀티 순위: 도달 라운드 내림차순 → 점수 내림차순. 죽으면 관전(라이벌 스트립 갱신 지속).

## 프로토콜 (relay payload)

- `{ t:'start', seed }` — 시작 신호(멱등). seed = 방코드.
- `{ t:'snap', round, lives, score, alive, name, char }` — 라운드 종료/사망 시 force, 그 외 스로틀.
