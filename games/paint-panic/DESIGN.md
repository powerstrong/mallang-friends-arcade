# 말랑프렌즈 물감대소동 (paint-panic)

> 2~6인 온라인 실시간 영역 칠하기 배틀. 60초 동안 아레나를 돌아다니며 바닥을 내 색으로 칠하고,
> 종료 시 가장 넓은 영역을 차지한 친구가 우승.

## 왜 이 게임인가 (라인업 관점)

| 기존 게임 | 플레이 모먼트 |
|---|---|
| 말랑프렌즈 점프 | 로컬 1~2인 액션 |
| 퀴즈배틀 | 라운드제 두뇌 대결 |
| 쓱쓱 | 비대칭(그리기/맞히기) 턴 기반 |
| 기계동물 러너 (프로토) | 솔로 러너 |

→ **전원이 동시에 같은 화면에서 부대끼는 실시간 멀티 액션**이 라인업에 없음.
영역 칠하기는 paint.io 류로 검증된 포맷이고, 한 입력(드래그)만으로 조작이 끝나
모바일 캐주얼에 최적. 점수가 "화면에 칠해진 색 면적"이라 관전만 해도 상황이 읽힌다.

## 핵심 룰 (v1)

- 아레나: 22×28 그리드 (세로형, game-shell 430px 기준).
- 라운드: 60초. 호스트(roster[0])가 시작 → 3초 카운트다운 → 동시 시작.
- 이동: 포인터 드래그(누른 곳을 향해 이동) 또는 WASD/방향키. 지나간 자리가 내 색으로 칠해짐.
- 덧칠 가능: 남의 영역 위를 지나가면 내 색으로 뺏음 (마지막에 칠한 사람이 주인).
- 아이템 (약 8초 간격, 시드 기반 동일 위치 스폰):
  - 💣 물감폭탄: 주변 반경 2.6셀을 내 색으로 콰광.
  - ⚡ 부스트: 3.2초간 이동속도 1.6배 + 붓 굵기 증가.
- 종료: 영역 % 순위 발표. 1인 입장 시 "혼자 연습" 모드로 시작 가능.
- 캐릭터: 광장 공용 5종(shared/character_sprites.js 초상화)을 색 버블에 넣어 사용. 신규 에셋 0개.

## 네트워크 모델 (릴레이, 서버 무권위)

`shared/relay.js` 만 사용 — worker/ 코어 변경 없음 (기여 게임과 같은 경로).

| 메시지 | 방향 | 내용 |
|---|---|---|
| `char` | 전원 브로드캐스트(echo) | 캐릭터/이름 선택 공유. 새 참가자 입장 시 재송신 |
| `start` | 호스트 → 전원(echo) | `{ seed, durationMs, roster:[{id,...}] }` — 슬롯/색 매핑 고정 |
| `p` | 각자 10Hz | `{ x, y }` 내 위치. 수신측이 경로를 따라 칠함 |
| `item` | 줍는 사람(echo) | `{ idx }` 아이템 클레임. DO가 중계를 직렬화하므로 **첫 수신자 = 주인** (동시 클레임 안전) |
| `result` | 호스트 → 전원(echo) | 호스트 그리드 기준 최종 집계 (클라 간 미세 발산 정리). 2.5초 내 미수신 시 로컬 집계 폴백 |

- 위치 10Hz + 아이템 클레임 ≈ 초당 11msg ≪ 릴레이 제한 40msg/s.
- 각 클라이언트는 수신 위치를 보간하며 모든 플레이어의 칠하기를 로컬에서 재현
  (페인트 자체는 메시지로 보내지 않음 → 대역폭 절약).
- 호스트 이탈 시: 종료 시점의 roster[0]이 result 송신을 승계.
- 라운드 중 입장한 참가자는 로비에서 대기 → 다음 판 자동 합류.
