# 협동대모험 — 핵심 재미 설계: "마음 도와주기" 모드 (v0.1 초안)

> 목적: 기존 횡스크롤 협동 플랫포머 위에 **"적을 무찌르지 않고, 곤란에 빠진 친구의 마음을 알아채고 도와주는"** 재미 레이어를 얹는다.
> 제약: **한 판 1~2분**(짧은 "한 판 더" 루프). 무빌드 Phaser + 기존 느슨한 공유상태 네트워크 모델 유지. 초등 저학년~고학년, 모바일.
> 상태: DRAFT — codex(엔지니어링)·gemini(UX) 리뷰 전.

---

## 0. 한 줄 컨셉
> **때리는 게임이 아니라 같이 있어주는 게임.** 달려가다 곤란에 빠진 친구를 만나면, 무슨 마음인지 알아채서 도와주고 다음 길을 연다.

## 1. 핵심 동사 (verb)
"무찌르기" 대신 **"알아채고 → 도와주기"**.
- 재미의 심장은 *심부름*이 아니라 **"무슨 마음/사정인지 진단하는 공감 퍼즐"**.
- 틀려도 벌 없음 → **귀여운 반응**(상대가 더 삐지거나 갸웃). 실패가 아니라 피드백.

## 2. 한 판(구역)의 구조
한 구역 = **메인 친구 1명 + 주변 NPC 약간**. 1~2분에 끝.

```
[달리기 이동(플랫포밍)]
   → [메인 친구 발견: 곤란에 빠져 길을 막고 있음]
   → [주변 NPC에게서 단서 수집]
   → [진단: 무슨 마음? 뭐가 필요?]
   → [해결: 정답 행동 1방]
   → [친구가 풀림 → 비켜줌/발판이 됨/동료 합류 + 보상]
   → [다음 구역으로 달리기]
```

### NPC 두 종류
- **힌트형 ❓**: 메인 해결의 단서. "쟤 아침부터 등 돌리고 있더라."
- **잡소리형 💬**: 세계관 양념/농담. 도움 X, 분위기 O. → **AI 대량생성의 안전한 자리**.

## 3. 해결 동사 사전 (1차 = 3개로 시작)
| 사정(감정) | 단서 신호 | 해결 동사 | 비고 |
|---|---|---|---|
| 😢 외로움/삐짐 | 등 돌림, 훌쩍 | **정답 이모트 달래기** (🙋/🙇/👍 중) | 감정적 해결. 기존 이모트 재사용 |
| 😱 무서움 | 뭔가에 막혀 떪 | **가로막은 위험/장애 치워주기** | 행동적 해결. 플랫포밍과 결합 |
| 😋 배고픔/잃어버림 | 배꼽시계, 두리번 | **가까운 곳에서 물건 찾아다 주기** | 짧은 탐색(심부름 최소화) |

> 동사 3개 × (캐릭터 × 감정 × 지형 × 소품) 조합 → 손맛 검증 후 동사 확장. **변주는 조합 수에서 나온다(텍스트 양 X).**

## 4. 진단 퍼즐 + 힌트 단계식
- 메인 친구에게 다가가면 **선택 UI**: 큰 아이콘 2~3개(이모트/행동) 중 고르기. (메뉴 마찰 최소, 읽기 부담 X)
- **힌트 티어링**: 처음 흐릿 → 헤매면 점점 친절. 저학년도 결국 풀고, 고학년은 한 방에.
- 정답 시 짧고 강한 연출(꽃가루/하트/합류).

## 5. 협동 설계 (게임의 뼈대 "갈라짐→합류"와 결합)
- 1P/2P가 **각자 다른 NPC**를 만나게 배치 → "내 쪽은 미안한 것 같던데?" / "그럼 🙇?" **정보를 합쳐야** 메인이 풀림.
- 잡소리·힌트가 단순 양념이 아니라 **협동 소통의 재료**가 됨.
- 메인 마지막 한 방은 **둘이 같이**(예: 동시에 정답 이모트, 또는 한 명이 위험 치우는 동안 한 명이 달램).
- 솔로 모드: NPC가 전부 내 동선에 들어오게 재배치, 마지막 한 방은 1인용으로 분기.
- 네트워크: 해결은 **이벤트성·넓은 판정·긴 활성창**(DO 권위) → 기존 모델과 정합. 정밀 실시간 협동 물리 없음.

## 6. 실패/긴장 (HP 없음)
- 체력바 없음. 낙사/위험은 **데미지가 아니라 깜짝 놀람 → 체크포인트 리스폰**(기존 그대로, 너그럽게).
- "진다"는 개념 약함 = 초딩 리텐션. 압박은 *공동운명*(2인)과 *진단의 호기심*에서.

## 7. AI 활용 (안전·실현성)
- **런타임 LLM을 아이에게 직접 X** (안전·비용·지연·오프라인 문제).
- **제작 단계 생성 → 사람 검수 → 콘텐츠 팩**으로 박아넣음. 사용자엔 "맨날 새 에피소드", 런타임은 안전·빠름·오프라인 OK.
- 양산 대상: **잡소리/힌트 풀** + **메인 에피소드의 살(누가/왜/대사)**. 뼈대(해결 동사·판정)는 손설계.
- 데이터 스키마(초안): `episode = { id, char, emotion, solveVerb, terrain, props[], hints[tier1..3], dialogue{ main, npcs[] } }`.
- (후순위) "만들기 모드": 부모-자녀가 AI로 에피소드 공동제작, 샌드박스.

## 8. 페이스/가독성 (플랫포머라서)
- 말풍선 1~2줄 + 이모지, **이동 막지 않음**, 탭=더보기/건너뛰기.
- "읽는 게임"이 아니라 "달리다 슬쩍 듣는" 느낌. 잡소리는 지나가면 머리 위 뿅.
- 1~2분 세션 안에 진단 1회가 핵심. 과하게 늘리지 않음.

## 9. 보상/메타
- 구역 클리어 = 별 1~3(기존) + **도와준 친구 = 동료 도감/스티커** 수집(귀여움 리텐션).
- 동료는 후속 구역에서 작은 도움(연출 위주, 밸런스 비권위).

## 10. 1차 수직 슬라이스(검증용) 범위 제안
- 구역 1개, 메인 친구 1명(예: 😢 삐진 토끼 → 정답 이모트), 힌트 NPC 2 + 잡소리 NPC 2.
- 해결 동사 1개(정답 이모트)만 먼저. 솔로로 손맛/페이스 검증 → 2인 정보합치기 → 동사 2·3 확장.
