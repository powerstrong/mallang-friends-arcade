# 이미지 제작 브리프 — 말랑프렌즈 별빛작전

게임은 `assets/runtime/` 아래의 최적화된 배포본만 직접 사용합니다. 새 원본은 저장소 밖 작업 공간에서 제작·검수하고, 채택한 결과만 아래 규칙으로 변환해 넣습니다.

## 런타임 계약

| 경로 | 용도 | 규격 |
|---|---|---|
| `runtime/tokens/*.webp` | 친구·장난감 전술 토큰 | 256×256 WebP, 투명 배경 |
| `runtime/props/*.webp` | 제어별·운반·탈출 목표물 | 256×256 이하 WebP, 투명 배경 |
| `runtime/ui/*.webp` | 허브와 결과 화면 일러스트 | 화면 용도에 맞춘 WebP |
| `runtime/ui/icon-192.png` | PWA 아이콘 | 192×192 PNG |
| `runtime/ui/icon-512.png` | PWA 아이콘 | 512×512 PNG |

## 공통 구도

- 상단 3/4 시점, 모든 전술 토큰의 카메라 각도 통일
- 한 이미지에 한 캐릭터만 배치
- 캐릭터 전체가 캔버스 안에 들어오고 사방 8% 이상 여백 확보
- 발 중앙과 시각적 무게중심을 모든 토큰에서 같은 위치에 정렬
- 그림자·바닥·프레임·글자·아이콘을 원본에 합성하지 않음
- 44×44px에서 종, 팀, 역할이 구분되는 큰 실루엣
- 라떼와 민트는 `world/assets/*_portrait.png`의 얼굴형·눈·털색·볼터치를 유지
- 기계 적은 `games/machine-animal-runner/assets/enemy-mech-*.png`의 둥근 파스텔 기계 화풍을 유지

## 금지

- 중세 갑옷, 검, 활, 방패, 마법 지팡이
- 고블린, 오크, 인간형 적
- 사실적 털, 공포 표현, 날카로운 흉기
- 글자, 로고, 워터마크, 남은 크로마키

## 채택 절차

1. 원본에서 배경과 알파 가장자리를 정리합니다.
2. 256px WebP 배포본을 만듭니다.
3. 44px로 축소해 실루엣과 팀 구분을 확인합니다.
4. 코드에 실제 배선할 파일만 `assets/runtime/`에 추가합니다.
5. 원본과 중간 산출물은 저장소에 중복 보관하지 않습니다. 필요하면 외부 작업 공간이나 Git 이력에서 관리합니다.
