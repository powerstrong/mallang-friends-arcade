# 말랑프렌즈 별빛작전 — 아트 가이드

> 목표: 기존 말랑프렌즈 캐릭터성을 훼손하지 않고 전술 보드에서 44px로 읽히는 자산을 만든다.  
> 최종 갱신: 2026-08-08

## 0. 제작·검수 원칙

- 이미지 생성 도구와 무관하게 이 문서의 캐릭터 정체성·시점·축소 가독성 계약을 지킨다.
- 원본 생성 PNG는 보존하고, 게임에는 `assets/runtime/`의 256px WebP와 앱 아이콘만 배선한다.
- 신규 생성은 실제 44px 플레이에서 캐릭터 혼동, 시점 불일치, 알파 결함이 확인될 때만 한다.
- 재발주 계약은 `assets/CLAUDE_ASSET_BRIEF.md`에 유지하되 특정 생성 서비스에 종속하지 않는다.

## 1. 기준 화풍

- 부드러운 파스텔 에어브러시풍
- 둥글고 포근한 몸 비율
- 은은한 타원형 볼터치와 크고 맑은 눈
- 얇은 갈색 계열 외곽선
- 무기·갑옷보다 캐릭터의 몸짓과 작은 생활 도구로 역할 표현
- 적 기계도 무섭거나 날카롭기보다 장난감 같은 둥근 실루엣

중세 판타지 갑옷, 검, 활, 고블린, 오크, 어두운 잉크 페인팅은 금지한다.

## 3. 기존 자산 재사용 계약

- 캐릭터 정체성 확인과 대화 초상화는 `world/assets/*_portrait.png`를 기준으로 한다.
- 이동 포즈 참고는 `world/assets/*_sheet_3x3.png`를 기준으로 한다.
- 현재 파일은 크로마키 배경이 포함된 것이 있으므로 그대로 토큰에 배선하지 않는다.
- 전술 토큰은 상단 3/4 시점, 한 캐릭터, 1:1 캔버스, 투명 배경, 44px 축소 검수 조건으로 별도 제작한다.
- 적 기준은 `games/machine-animal-runner/assets/enemy-mech-*.png`와 `boss-mech.png`다.
- 저장소 밖 재사용은 `ASSET_POLICY.md`에 따라 별도 허가가 필요하다.

## 4. 색 체계

- 친구 선택/이동: 하늘색 `#68b7ff`
- 친구 보호/회복: 민트 `#73dfc2`
- 적 위협: 코랄 `#ff7f8f`
- 목표/상호작용: 별노랑 `#ffd75a`
- 배경: 라일락 `#f4efff`, 짙은 글자 `#352d4f`
- 기계: 크림 화이트 + 장난감 파랑, 오작동 코어만 코랄

팀을 빨강/파랑 전쟁 진영처럼 표현하지 않는다. 색은 위험과 상호작용 정보를 전달한다.

## 5. 필요한 자산 우선순위

### 현재 채택

1. 라떼·민트·삐걱봇·콩콩봇·반짝포탑·덩치곰 토큰
2. 제어별 on/off, 배터리 수레, 탈출 표식
3. 작전판 배경, 결과 스티커, 192/512 앱 아이콘
4. 이동·위협·목표·확정 효과는 색만 의존하지 않는 CSS로 구현

### 채택하지 않음

1. `assets/tiles/`의 바닥·벽·물: 44px에서 질감이 너무 조밀하고 반복 경계가 보여 CSS 타일을 사용한다.
2. `assets/art/style-anchor-v1.png`: 폐기된 중세 판타지 방향이다.
3. 병아리·토끼·햄스터 토큰: 후속 챕터 합류 전까지 다운로드·렌더 비용을 늘리지 않는다.

### 확장

- 모찌 토끼와 푸딩 햄스터 토큰
- 표정 초상화 변형
- 추가 광장 구역과 장난감
- SFX와 승리 연출

## 6. 생성 프롬프트 불변조건

- 각 캐릭터 생성 시 기존 초상화를 **정체성 레퍼런스**로 제공한다.
- 얼굴형, 털색, 눈색, 볼터치, 귀·꼬리 비율을 바꾸지 않는다.
- 새 복장보다 몸짓·빛·작은 도구로 역할을 구분한다.
- 한 이미지에 한 자산만 생성한다.
- 배경 제거가 필요하면 평면 크로마키→로컬 제거→알파·44px 검수 순서를 지킨다.
- 일관된 카메라 각도와 발 기준점을 유지한다.

## 7. 폐기 자산

`assets/art/style-anchor-v1.png`는 사용자 방향 변경 전 생성된 중세 판타지 시안이다. 기사·궁수·고블린·오크와 어두운 페인팅 스타일이 현재 세계관에 맞지 않으므로 **참고·파생·배선 금지**다. 삭제 여부는 사용자가 정리 작업을 요청할 때 결정한다.

`assets/tokens/`, `assets/props/`, `assets/ui/`의 선행 생성 PNG는 원본 보관용이다. 채택본은 `assets/runtime/`으로 축소·변환해 배선했다. 현재 토큰은 정면 카드형 시점이라는 약점이 있으나 44px에서 친구/적 실루엣과 팀 구분은 확인됐다. 후속 재생성 우선순위는 ‘더 강한 상단 3/4 시점’이며, 출시를 막는 결함으로 보지는 않는다.
