# 말랑프렌즈 키우기 — 단계와 게이트

`mallang-idle` · v1 범위와 진행 순서

> 기능 수를 진행률로 착각하지 말 것.
> 진행률은 **플레이어가 "막힘 → 성장 → 돌파"를 다시 하고 싶어지는가**로만 측정한다.

각 단계는 **게이트를 통과해야** 다음으로 간다. 게이트는 기능 개수가 아니라 플레이 감각으로 판정한다.

## P0 — 하네스 ✅ 완료

UI 없음. 숫자와 검증 장치만 만든다.

**범위**
- `engine/balance.js` — 상수 단일 원천
- `engine/combat.js` — 순수 결정론 전투/성장 모델 (seeded RNG, 시간은 주입)
- `engine/save.js` — `version` + `migrateSave()`
- `tools/sim.js` — 헤드리스 시뮬레이터 (`--minutes` / `--hours` / `--json`)
- `tools/tune.js` — 파라미터 그리드 서치 (120조합 11.6초)
- `tests/balance.test.js` — 지표 회귀 테스트
- `?dev=1` 치트 패널 (UI가 생기는 즉시 붙일 수 있게 준비)

**게이트** — 통과
> 24시간 시뮬이 예외 없이 완주하고, [BALANCE.md](BALANCE.md)의 지표 8종이 출력된다.

## P1 — 코어 루프 ★ 최대 관문 · 구현 완료, 게이트 판정 대기

**범위**
- 횡스크롤 자동 전진 전투 (파티 1명)
- 골드 · 강화 3축(ATK / ASPD / GOLD) · `x1`·`x10`·`MAX`
- 보스 관문 (25초 DPS 체크, 자동 재도전 = 공식 규칙)
- 오프라인 보상 (골드만)
- 최소 UI — 예쁠 필요 없음. 숫자가 읽히고 버튼이 눌리면 된다

**게이트**
> **5분 플레이하고 나서 한 번 더 강화하고 싶어진다.**
> 여기서 막히면 위로 못 올라간다. 장비·펫·스킬을 붙여서 해결되는 문제가 아니다.

이 게이트는 **사람만 판정할 수 있다.** 시뮬 지표가 전부 초록이어도 재미없을 수 있다.
반대로 재밌다고 느껴도 지표가 빨간색이면 아직 통과가 아니다 — 둘 다 필요하다.

## P2 — 편성 ✅ 완료

**범위**
- 말랑프렌즈 6명 — 모찌(공격 +20%) · 피치(속도 +18%) · 푸딩(골드 +25%) ·
  라떼(보스 피해 +35%) · 민트(이동 -40%) · **별사탕 수달(별조각 +35%, 8차 추가)**
- 해금 = 스테이지 도달(1/5/22/55/90/120 — 8차 재배치: 30분 전부 소진 문제 해소),
  슬롯 = 진행 해금(1/10/40). 가챠 없음
- 편성 1번 친구가 화면의 주인공 스프라이트가 된다
- 캐릭터별 강화는 P3 로 이연

**게이트** — 통과 (자동 검증)
> 누구를 넣을지가 실제로 고민된다 — **정답 하나로 수렴하지 않는다.**

`tests/balance.test.js` 가 "파밍 최적 조합 ≠ 돌파 최적 조합"을 매번 검사한다.
수렴하는 순간 테스트가 실패한다 — 캐릭터가 스킨이 되는 것을 코드가 막는다.

## P3 — 영구 성장축 ✅ 완료 (유물)

환생/프레스티지 **대신** 우상향만 하는 축들로 장기 수명을 만든다.

**구현: 별조각 + 유물 3종**
- 별조각 = 보스가 주는 두 번째 재화. **실패해도 준다** — 벽에 막힌 시간이 그대로
  성장이 되는 구조라, 벽에서 시도할 수단이 "골드 파밍" 하나에서 둘로 늘어난다
- 유물: 별의 망치(공격 ×1.06/Lv) · 별의 곳간(골드 ×1.06/Lv) · 별의 나침반(보스 피해 ×1.09/Lv)
  (초안 ×1.08/×1.12 는 시뮬 재튜닝에서 인플레가 드러나 하향 — `engine/balance.js` RELICS 가 원천)
- 배수는 레벨당 **곱연산** — 선형이면 상대 이득이 줄어 지수 벽을 영구히 못 따라간다
- RNG 없음(결정론 유지). 장비·승급·계정레벨은 P4 이후 후보로 이연

**게이트** — 통과 (자동 검증)
> 벽에 막혔을 때 시도할 수 있는 수단이 **둘 이상**이다.

`tests/balance.test.js` 의 "유물이 벽을 깬다"가 직접 증명한다: 골드 강화를 봉인한
같은 막힘 상태에서, 조각→나침반 세계는 벽을 깨고 조각을 무시한 세계는 못 깬다.
측정: 24h 연속 플레이 최장 벽 90분 → 54분, 도달 스테이지 172 → 227.

## P4 — 콘텐츠 ✅ 완료

**구현**
- **별빛 시련** (보스 러시 던전, 하루 3회) — 결과는 현재 전투력으로 결정론 계산,
  화면은 결과 팝업으로 연출(조작 없는 자동 전투라 "달리는 척"은 시간 낭비).
  첫 보스는 본편 보스의 35%에서 시작해 ×1.35 씩 — 방금 그 층을 깬 유저가
  몇 연승은 하고 벽을 만나는 곡선. 보상 = 격파당 별조각 + 골드
- **일일 과제 3종** (처치 200 / 강화 20 / 보스 도전 10 → 별조각) — 진행도는
  누적 stats − 자정 스냅숏이라 전투에 새 카운터를 심지 않았다
- **도감** — 만난 몬스터·보스 기록(20종), 못 만난 칸은 실루엣 + ???
- HP·생존형 던전은 **POST-v1 후보로 이연** — HP 축 도입은 밸런스 전면 재작업이라
  광장 연동과 함께 판단한다

**게이트** — 부분 충족 (문구 하향, 2026-08-16)
> 매일 열어볼 이유가 생긴다. ("하루 두 번"은 아직 미증명 — codex 리뷰)

던전 3회는 한 번에 소모 가능하고 과제는 하루 1회 리셋이라, 현재 구조가 보장하는 것은
"하루 한 번"까지다. 시간대별 충전·복귀 보너스 같은 재접속 구조는 사람 게이트 통과 후
실험 항목으로 남긴다.

## POST-v1 — 아케이드 메타게임

이 플랫폼에서만 가능한 장기 차별점. **코어 루프가 재밌다는 증거가 나온 뒤에만 착수한다.**

**범위**
- 광장 아바타에 전투력 · 스테이지 뱃지 표시
- 광장에서 마주친 사람과 즉석 자동 대전
- 부스 게임 성적 → 키우기 재화 / 키우기 보상 → 부스 게임 스킨
- 글로벌 랭킹 · 기기 간 동기화

**전제 (중요)**
> 이 시점에는 저장과 **주요 경제 계산 자체를 서버 권위로 옮겨야 한다.**
> 서버 시간만 쓰는 것으로는 부족하다. 다른 플레이어에게 영향을 주는 경제가 되는 순간
> 클라이언트 계산은 신뢰할 수 없다.

관련 구조는 [platform_architecture_facts](../../README.md) 참고 — 정적 배포와 API 워커가
다른 오리진이고, 게임 경로는 `games/registry.js` · `worker/src/room.js` · `worker/src/world.js`
세 곳에 동기화해야 한다.

## 범위를 크게 잡는다는 것의 의미

이 로드맵은 일반적인 MVP보다 훨씬 크다. 단 **순서는 협상 대상이 아니다.**

- 크게 잡는다 = P2~P5를 실제로 다 만든다
- 크게 잡는다 ≠ P1 게이트를 건너뛰고 P3를 시작한다

며칠간 자동으로 개발을 돌리는 이상, 사람이 매 변경을 보지 못한다.
그래서 **게이트와 지표 회귀 테스트가 유일한 브레이크**다. 이것들을 우회하면
"기능은 20개인데 재미없는 키우기"가 완성된다.
