# 말랑프렌즈 키우기 — 공식 규칙 전면 재심 (19차)

`mallang-idle` · 2026-08-17 · 재심 권한 위임: 사용자 *"공식 규칙 또한 니가 만든 거다.
필요하면 뒤집어라."*

> 이 문서는 v1 을 만들며 세운 모든 "공식 규칙"을 플레이어 관점에서 다시 심사한
> 기록이다. 판정은 넷 중 하나: **유지 재승인** / **수정** / **뒤집기** / **실험**.
> "전에 그렇게 정했다"는 판정 근거가 될 수 없다 — 당시의 이유가 지금도 유효한지만 본다.
> 뒤집은 규칙의 구현이 끝나면 원 문서(CORE_LOOP 등)를 함께 갱신한다.

---

## 0. 새로 제정하는 메타 규칙

1. **규칙 재심 원칙** — 모든 공식 규칙은 재심 대상이다. "사용자 결정"·"v1 스펙"이라는
   이유만으로 동결하지 않는다. 단, 뒤집을 때는 이 문서에 원래 이유·새 근거·검증
   방법을 남긴다. (근거 없는 뒤집기는 규칙이 아니라 표류다.)
2. **성의 3요소** (18차 제정, 여기 편입) — 도전성 콘텐츠는 ① 진입 전환 ② 시작 신호
   ③ 과정 가시화를 갖춘다. 반복 피로는 스킵으로 풀고, 의식 제거로 풀지 않는다.

---

## 1. 심사 기준 — 플레이어 관점 3문

1. 이 규칙이 **지금도** 플레이어의 재미를 지키는가?
2. 규칙을 만들 당시의 이유(제약·미검증·단순화)가 아직 유효한가?
3. 뒤집으면 무엇이 좋아지고, 무엇이 위험한가? 위험은 어떻게 검증하나?

---

## 2. 핵심 발견 — 문서가 스스로 모순을 안고 있었다

[CORE_LOOP.md](CORE_LOOP.md) 4절은 이 게임의 **의미 있는 긴장이 딱 둘**이라고 명시한다:

> 1. 지금 DPS에 넣어 돌파할까 / GOLD에 넣어 장기 성장할까
> 2. **지금 보스를 재도전할까 / 더 파밍하고 갈까**

그런데 같은 문서 3절의 공식 규칙이 **2번 긴장을 UI에서 제거**했다:

> 보스 재도전: 자동 재도전이 공식 규칙 — ON/OFF 토글은 v1 스펙에서 제외

즉 우리 스스로 "이 게임의 진짜 선택은 두 개뿐"이라 정의해 놓고, 그중 하나를
"엔진에 대기 상태가 없고 끌 이유도 검증되지 않았다"는 **구현 편의**로 봉인했다.
이것이 이번 재심의 가장 큰 수확이고, 뒤집기 1순위(R1)다.

## 3. 판정 요약표

| # | 규칙 (출처) | 당시 이유 | 판정 |
|---|---|---|---|
| 1 | 보스 자동 재도전 단독, 토글 없음 (CORE_LOOP 3) | 엔진에 대기 상태 없음·끌 이유 미검증 | **뒤집기 → R1** |
| 2 | 오프라인 효율 0.25 · 상한 8h 고정 (CORE_LOOP 5) | 프로토타입 clamp 세 줄이면 충분 | **뒤집기 → R2** |

| 4 | 던전 3회/일 즉시 소모·고정 규칙 (ROADMAP P4) | 단순화 | **뒤집기 → R4** (케이던스+변칙) |

| 6 | 첫 벽 5층 ×1.3 (8차) | 의도된 첫 벽 | **실험 → R6** (개편 후 재측정) |
| 7 | 사망 없음 — 실패는 시간초과 하나 (CORE_LOOP 3) | 메시지 명확성 ("공격력이 부족하구나") | **유지 재승인** |

| 11 | 가챠 없음, 해금 = 스테이지 도달 (P2) | 애착·정직함 | **유지 재승인** |
| 12 | 결정론·seeded RNG·시간 주입·BALANCE 단일 원천 (AGENT_PROTOCOL) | 시뮬=게임 동일성 | **유지 재승인** — 이 재심 자체가 이 규칙 덕에 가능했다 |
| 13 | 표현 계층은 엔진을 읽기만 (개편 트랙) | 지표 정직성 | **유지 재승인** |
| 14 | 지표 회귀와 함께 커밋·허용범위 임의 완화 금지 (AGENT_PROTOCOL) | 조용한 붕괴 방지 | **유지 재승인** |
| 15 | 설명 텍스트 금지(코치마크)·인트로 최소·탭 점진 공개 | 온보딩 부담 최소화 | **유지 재승인** |
| 16 | 오프라인은 파밍만 대행(진행 없음) (CORE_LOOP 5) | "내가 플레이한 느낌" 보존 | **유지 재승인** — 수치만 R2 |
| 17 | 멀티탭 단일 소유권·저장 규칙 | 세이브 정합성 | **유지 재승인** |

유지 재승인 = "규칙이라서"가 아니라 **재심했고 지금도 옳다**로 승격. 7~17번의 이유는
전부 지금도 성립한다(특히 12~14번은 이번 재심의 근거 데이터를 만들어 준 장본인이다).

## 4. 뒤집기 실행 계획 (우선순위순)

### R1. 벽에서의 결정권 — "도전 / 파밍" 모드 (뒤집기 1순위)

- **무엇을**: 자동 재도전은 **기본값으로 유지**하되(방치 순수성), 보스 구간에
  **파밍 모드 토글**을 도입한다. 파밍 모드 = 보스를 건너뛰고 잡몹 파밍 지속.
  도전 모드 복귀 시 즉시 보스 재도전 + **도전 의식**(성의 3요소 — 짧은 집중
  연출·카운트인·분노 프레이밍은 이미 있다). 벽 상태(연속 실패 N회)에서는
  "필요 DPS까지 X%" 정직 표시와 함께 코치마크로 선택지를 알린다.
- **왜**: 2절의 내부 모순 해소 — 문서 스스로 인정한 "진짜 선택"을 플레이어 손에
  돌려준다. 벽에 막힌 시간이 "지켜보는 시간"에서 "결정하는 시간"이 된다.
- **엔진 영향**: `state.farmMode`(boolean) 하나. 결정론 유지 — 시뮬 시나리오에
  farmMode 온·오프 경로 추가. 저장 v6 마이그레이션(기본 false).
- **검증**: ① 밸런스 — 파밍 모드가 항상 최적이면 실패(보스 별조각·돌파 이득이
  도전을 정당화해야 한다. "실패해도 별조각" 규칙이 이미 방어선) ② 시뮬 24h 완주
  ③ 브라우저 — 토글·의식·코치 배선.
- **리스크**: 선택지가 하나 늘어 온보딩 부담 — 코치마크 1회 + 벽 상태에서만 노출로
  상쇄. 기본값이 현행과 동일하므로 기존 세이브 체감 변화 0.

### R2. 오프라인 보상을 성장 축으로 (효율 0.25·상한 8h 고정 해제)

- **무엇을**: 유물 4호 **별의 모래시계** — 오프라인 효율 +5%p/Lv (0.25 → 상한 0.6),
  상한 시간 8h → 최대 12h 확장(레벨 구간별). 별조각 소비처 확장을 겸한다.
- **왜**: 복귀 보상이 곧 재접속 동기다. 고정 0.25 는 "복귀가 시시하다" 위험이 있고,
  방치형에서 오프라인 축은 장기 성장의 표준 재미다. 파밍만 대행(진행 없음) 원칙은
  유지 — **양만** 성장시킨다.
- **검증**: 시뮬 세션 모델(오전/저녁 접속) 재측정 — 24h 도달·벽 지표 허용 범위 확인,
  이탈 시 성장 기울기 조정. 유물 밸런스는 기존 3종과 같은 곱연산 문법.

### R3. 게이트 직렬화의 범위 명확화 (수정)

- **무엇을**: "사람 게이트 통과 전 착수 금지"의 적용 범위를 **POST-v1 인프라**
  (서버 권위·랭킹·광장 경제)로 한정한다. **게임 깊이 작업**(영구 성장층·규칙 개선
  R1~R6)은 게이트와 병행한다.
- **왜**: 게이트의 원래 목적은 "재미없는 코어 위에 장식을 쌓지 마라"였다. 영구
  성장층은 코어 재미의 층이지 장식이 아니다. 반면 서버·랭킹은 코어가 확정돼야
  하는 진짜 후행 작업 — 원래 의도는 이 구분이었는데 문구가 전부를 막고 있었다.
- **효력**: 즉시. ROADMAP 문구 갱신.

### R4. 던전 케이던스·요일 변칙 (3회 즉시 소모 해제)

- **무엇을**: ① 3회 일괄 → **충전형**(최대 3, 자정 전량 대신 8시간당 1충전) —
  "아침에 2번, 저녁에 1번"의 하루 두 번 리듬 ② **요일 변칙** — 결정론 유지
  (요일이 시드): 예) 화요일 = 공속의 날(공속 편성 보너스 ×2), 금요일 = 골드의 날.
  편성 선택(P2 게이트)과 맞물려 "오늘은 누구를 넣지"가 매일 갱신된다.
- **왜**: P4 게이트가 스스로 "하루 두 번 미증명"이라 적어 두었다. 던전 의식(18차)으로
  "하는 맛"은 생겼으니, 이제 "또 올 이유"를 붙일 차례.
- **검증**: 충전 로직 결정론 테스트, 자정·시계 역행 방어(오프라인과 같은 clamp 문법),
  요일별 시뮬 지표가 허용 범위 안인지.

### R5. 과제 목표 진행도 비례화 (수정)

- **무엇을**: 처치 200/강화 20/보스 10 고정 → 구간별 스케일(예: safeStage 구간에
  비례, 상한 있음). 후반에 과제가 "로그인만 하면 끝"이 되는 것을 막는다.
- **검증**: 각 구간 시뮬에서 "하루 활동으로 완료 가능"이 유지되는지.

### R6. 첫 벽 재측정 (실험)

- **무엇을**: 전투 개편(연출·시트) 이후 첫 벽 체감이 달라졌을 수 있다 — 5층 ×1.3 을
  고정값이 아니라 **측정 대상**으로 되돌린다. 개편 전 수치로 정한 값이기 때문.
- **방법**: 시뮬 첫 5분 지표 + 사람 첫인상 게이트와 함께 판정. 숫자 변경은 그 뒤.

## 5. 실행 순서와 현재 상태

```
R3 (정책 — 즉시 발효) ✅ 이 문서로 발효
R1 (벽 결정권)         ✅ 구현 완료 (20차) — 엔진 farmMode·challengeNow(세이브 v6) +
                          파밍/도전 토글 + 벽 코치(3연속 실패) + 클로드 리뷰 APPROVE
                          (LOW 3건 전부 반영: 반환값 가드·경로 테스트·켜기/끄기 대칭)
R4 (던전 케이던스·변칙)  ← 다음 착수점. 18차 의식 위에 얹는다
R2 (오프라인 유물 4호)   ← 별조각 소비처 확장 겸
R5 (과제 비례화)         ← 소형
R6 (첫 벽 재측정)        ← R1~R5 반영 후 시뮬 + 사람
영구 성장층 설계         ← 별도 대형 트랙. R2·R6 결과를 흡수한다
```

> 리뷰 채널 변경 (20차): 구현 리뷰는 codex 가 아니라 **클로드 리뷰 세션**(서브에이전트)
> 이 한다 — 사용자 지시. R1 이 첫 적용: 불변조건 4종 통과 판정 + LOW 3건 발견·반영.

각 항목은 AGENT_PROTOCOL 3절 그대로 **측정과 함께** 커밋한다. 이 문서의 판정을
바꿀 때는 새 근거를 이 문서에 추가한다 — 조용한 번복 금지.
