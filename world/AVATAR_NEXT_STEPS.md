## ~~P0-1~~ 완료(2026-08-18). 모자·안경 부착감 — 결과 기록

**증상**: 모자가 캐릭터 머리와 다르게 움직여 쓰고 있는 느낌이 안 남.

**실측 원인 2가지** (정본/레이어 시트의 셀별 콘텐츠 top(y) 측정, 384² 기준):

| 레이어 | 실측 | 문제 |
|---|---|---|
| 정본 바디 머리 top | row0 [10,10,10] / row1 [12,12,12] / row2 [15,15,15] | 행 내 균일(기준) — 머리 까딱임은 셀 그림 안의 기울기/1px 이동뿐 |
| 베레모 top | row0 [8,8,8] / row1 [9,9,9] / row2 [3,3,3] | **방향별 머리와의 간격이 앞+2 / 옆+3 / 뒤+12px** — 방향 돌 때 모자가 점프, 뒷모습에서 붕 뜸 |
| 안경 top | row0 [43,43,43] / row1 [43,38,38] | **옆모습 걷기 셀에서 5px 위로 점프** — 4박자 재생(A→정지→B→정지)마다 안경이 들썩 |

**원인 해석**: ① 착용 프롬프트(p5v2)의 "걷기 셀에서도 모자 위치·크기·각도는 정지 셀과 동일" 지시가 **캔버스 기준 고정**으로 해석돼 머리의 미세 움직임을 모자가 안 따라감 + ② 방향(행) 간 상대 높이 검수 기준이 없었음.

**실행 결과(2026-08-18, 커밋 552088f)** — 계획 1·3은 그대로, 2는 안경에서 발동:
1. `--fit-head REF --fit-anchor global|row` 구현(모자=global 갭 통일, 안경=row 걷기 점프만 제거). 잔차 게이트 그룹 내 ≤1px + **액세서리 밴드(48px)만 보존**(이동 고스트 스펙 제거). 베레모 갭 앞-2/옆-3/뒤-5 → 전부 -2 통일 PASS.
2. **측정 함정 실측**: cell_metrics 의 최대 블록이 추출 고스트(몸 재음영, 셀당 200~400px)를 잡아 첫 시도가 에셋을 깨뜨림 → `block='first'`(최상단 유의미 블록) 측정으로 해소. 추출도 `--extract-fine`(침식 없는 측지 이력 연결) 추가 — 모자 고스트 자연 배제.
3. **안경은 재생성이 정답이었다**: 철사테(2px)가 추출 침식에 소멸(셀당 알파 25px 파편) → 네이비 뿔테로 재생성(r0/r1 top 37/38 균일, 걷기 점프 0). fine 모드는 눈 재음영을 물어와 안경은 **기본 추출** 유지.
4. 프롬프트 '정지 셀과 동일' → '두상 기준 상대 고정' 교체 완료(p5v2·p6v2). 합성 9셀 육안 검수 완료 — 실기기 재확인은 P1.

## P3. 기술 부채·인프라

1. **정적 배포 랙 20~40분(2026-08-17 관측)** — Cloudflare 쪽 git 연동 빌드가 병목. 대시보드(Workers & Pages → 프로젝트 → Deployments)에서 빌드 큐/실패 확인 필요. 저장소에서는 통제 불가 — **뱃지 버전(vNN)과 sw.js CACHE 동기 관례**로 반영 여부 판별(현재 v41).
2. **카탈로그 클라/서버 미러 수동 동기화** — 아이템 추가가 잦아지면 사고 확률↑(한쪽만 고치면 서버가 프리셋으로 치환 — "저장했는데 남에게 기본 코디" 증상). §11 CI 해시 비교를 B단계 전에 조기 도입 권장(worker/tests에 두 파일 파싱 비교 테스트 1개면 됨).
3. **속옷 비침의 근본 해결** — 분리옷 실루엣 규칙("탱크톱·반바지를 완전히 덮기")은 프롬프트 규율에 의존. 크롭티·짧은 치마를 열려면 **bare-base 시트**(속옷을 피부로 편집한 바닥 전용 시트) 1장 생산이 정공법(마네킹 비노출 원칙과 무관 — 바닥 레이어 전용).
4. **썸네일 캐시** — 아이템이 20+가 되면 LRU 24를 아바타/썸네일로 분리 검토.
5. **오프라인 첫 방문** — sw.js PRECACHE에 아바타 에셋 미포함(저우선, 재방문은 런타임 캐시로 커버).

## 함정 목록 (실측 누적)

- **부유 레이어 생성 금지** — 반드시 착용 편집("Image 1을 편집, 해당 아이템만 변경, 불변 조건 나열").
- **상·하의 프롬프트 2대 규칙**: ① "모든 9셀에서 X를 Y로 교체. 어느 셀에도 X가 보이면 실패" 강조(치마 1차가 지시 통째 무시, 차분 0px 전례) ② 실루엣은 탱크톱/반바지를 완전히 덮는 크기만. 추출 후 alpha px 즉시 확인.
- **액세서리 프롬프트에 "정지 셀과 동일" 금지** — 캔버스 고정으로 해석돼 머리를 안 따라감(P0-1). "두상 기준 상대 고정"으로 쓸 것.
- **액세서리는 두꺼운 디자인만** — 얇은 철사테(2px)는 차분 추출 침식에 소멸(구 안경 셀당 25px 파편). 뿔테급 두께로 생성.
- **액세서리 레이어 측정은 first-block** — 최대 블록은 추출 고스트를 잡는다(P0-1 1차 시도가 에셋 파손). fit-head 가 내부 처리하므로 수동 측정 시에만 주의.
- 모자=--extract-fine / 안경=기본 추출 비대칭은 실측 결과(fine 이 안경에선 눈 재음영 고스트를 물어옴) — build_assets.sh 주석 참조.
- **align.json(row_dy=[0,4,10])은 마네킹 세대 고유값** — 마네킹 재생성 금지.
- 차분 추출 시 아이템 색이 마네킹 표면색(살구 피부·흰 탱크톱·회색 반바지)과 비슷하면 구멍.
- 크로마키 그린 #00FF00 + "방송용 그린스크린" 문구. 초록 계열 아이템은 마젠타 키 전환 필요(미구현).
- 분리옷 추출 단계의 `QA: FAIL`은 전신 지표를 부분 레이어에 적용한 노이즈 — 착용 시트 `--metrics-only` PASS + 합성 육안이 실제 게이트.
- `*.log`는 gitignore — 프롬프트 .md와 raw PNG만 커밋.
- `_mannequin.png` **단독** 렌더 경로 금지 — 분리옷 바닥 레이어로만(sanitize가 top+bottom 완비 보장).
