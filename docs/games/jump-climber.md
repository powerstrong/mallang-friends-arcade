# 말랑프렌즈 점프

점프하며 최대한 높이 올라가는 1~2인 로컬 플레이 게임입니다.

## 플레이 방법

1. 세 말랑프렌즈 캐릭터(민트 고양이·라뚜·햄스터) 중 하나를 선택합니다.
2. 얼굴을 커스터마이즈해서 나만의 캐릭터를 만듭니다.
3. 화면을 탭하거나 버튼을 눌러 점프하며 최대한 높이 올라갑니다.
4. 2인 플레이라면 같은 기기에서 동시에 플레이하고 결과를 비교합니다.
5. 최고 높이(m)가 점수입니다.

---

## 조작

- **모바일**: 화면 탭
- **PC**: 마우스 클릭 또는 스페이스바
