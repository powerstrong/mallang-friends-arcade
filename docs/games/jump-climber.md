# 말랑프렌즈 점프

점프하며 최대한 높이 올라가는 1~2인 로컬 플레이 게임입니다.

![말랑프렌즈 점프 플레이](../media/demo.gif)

---

## 기본 정보

| 항목 | 내용 |
|------|------|
| 인원 | 1~2명 |
| 플레이 방식 | 로컬 동시 플레이 |
| 상태 | PLAYABLE |
| 제작자 | powerstrong |

---

## 플레이 방법

1. 말랑프렌즈 캐릭터를 선택합니다.
2. 화면을 탭하거나 버튼을 눌러 점프하며 최대한 높이 올라갑니다.
3. 2인 플레이라면 같은 기기에서 동시에 플레이하고 결과를 비교합니다.
4. 최고 높이(m)가 점수입니다.

---

## 조작

- **모바일**: 화면 탭
- **PC**: 마우스 클릭 또는 스페이스바
