# 작업: 말랑프렌즈 퀴즈배틀 UI 아트 에셋 일괄 생성

너는 웹 게임 프로젝트의 UI 아트 에셋을 생성한다. 반드시 `imagegen` 스킬(내장 `image_gen` 툴)을 사용해 PNG로 저장한다. 텍스트/글자/로고 문구는 별도 지정이 없으면 넣지 않는다.

## 스타일 가이드 (모든 이미지 공통)
- 부드러운 파스텔 치비 마스코트 톤. 얇고 둥근 진갈색(#3a2a1a 정도) 외곽선, 단순 플랫 셰이딩, 큰 반짝이는 눈, 분홍 볼.
- 색감: 파스텔 라벤더 / 크림 / 민트 / 피치 톤. 채도 중간, 명도 높음.
- 글자/텍스트/로고/숫자 절대 금지(별도 지시가 없는 한).
- 그림자/그라데이션/질감은 최소화하고 깔끔한 셀 셰이딩으로.
- 캐릭터는 모두 의인화 두발 동물, 큰 머리 작은 몸. 기존 `prototypes/jump-climber/assets/토끼 메인 이미지.png`, `병아리 메인 이미지.png`, `고양이 메인이미지.png`, `라떼 메인 이미지.png`, `햄스터 메인 이미지.png`를 스타일 레퍼런스로 보고 같은 톤을 유지해라.

## 스타일 레퍼런스 (시작 전 view)
- `prototypes/jump-climber/assets/토끼 메인 이미지.png`
- `prototypes/jump-climber/assets/병아리 메인 이미지.png`
- `prototypes/jump-climber/assets/고양이 메인이미지.png`

## 배경 처리
- 투명이 필요한 모든 이미지: 완벽히 평평한 단색 #ff00ff(마젠타) 크로마키 배경에 생성한 뒤 imagegen 스킬의 크로마키 워크플로우로 배경 제거해 저장.
- 캐릭터/요소에 #ff00ff 색은 절대 사용하지 말 것.
- 배경 이미지(`quiz_bg.png` 한 장)만 불투명, 나머지 9장은 모두 투명 배경.

## 생성 목록 (총 10장, 모두 정확한 경로에 저장)

### 1. `prototypes/mallang-quiz-battle/assets/quiz_bg.png` — 불투명, 1024x1536 세로
퀴즈배틀 화면 배경. 동화 같은 파스텔 도서관/매직 교실. 떠다니는 책, 별, 구름, 작은 잉크병, 마법 펜, 부드러운 빛줄기. 채도 낮고 UI 가독성을 해치지 않도록 저대비. 캐릭터 없음. 글자 없음. 위쪽이 더 밝고 아래쪽이 살짝 어둡게.

### 2. `prototypes/mallang-quiz-battle/assets/quiz_logo.png` — 투명, 1024x384 가로
로고 배너. 5마리 마스코트(토끼/햄스터/병아리/강아지/고양이) 작은 치비 버전이 ❔🧠💡 등 작은 퀴즈 소품과 함께 한 줄로 배치. 가운데에 큰 별/하트/리본 같은 장식. 글자/문구 없음 — 로고는 별도 텍스트 합성. 좌우 여백 적당히.

### 3. `prototypes/mallang-quiz-battle/assets/hint_bulb.png` — 투명, 512x512
귀여운 노란 전구 마스코트. 약간 작은 얼굴(눈/입). 빛이 켜진 듯 옅은 노란빛 후광, 주변에 작은 ✨ 3-4개. 전구 아래 금속 부분은 부드러운 회색. 한 마리만, 정사각형 중앙 정렬.

### 4. `prototypes/mallang-quiz-battle/assets/stamp_o.png` — 투명, 512x512
정답 도장. 두꺼운 초록색 둥근 링(도장 자국 느낌), 안쪽이 살짝 비어있음. 링 일부에 작은 ✨와 하트 1개 떠 있음. 살짝 기울어진 배치(약 -8도). 도장 자국 특유의 거친 가장자리 약간.

### 5. `prototypes/mallang-quiz-battle/assets/stamp_x.png` — 투명, 512x512
오답 도장. 두꺼운 산호색/빨강(#ef4444 톤) X자, 도장 자국 느낌. 살짝 풀죽은 작은 눈물 한 방울 옆에. 살짝 기울어짐(약 +8도). 거친 가장자리 약간.

### 6. `prototypes/mallang-quiz-battle/assets/emote_sparkle.png` — 투명, 256x256
정답 시 캐릭터 머리 위에 뜨는 ✨ 이모트 대체. 큰 별 1개 + 작은 별 3개 + 작은 노란 동그라미가 burst 형태로. 색은 따뜻한 노랑/주황. 정사각형 중앙.

### 7. `prototypes/mallang-quiz-battle/assets/emote_drop.png` — 투명, 256x256
오답 시 머리 위에 뜨는 💧 이모트 대체. 통통하고 귀여운 파란 물방울 1개(하이라이트 있음). 옆에 더 작은 물방울 1개. 표정 없음. 정사각형 중앙.

### 8. `prototypes/mallang-quiz-battle/assets/emote_zzz.png` — 투명, 256x256
시간초과 시 머리 위 😴 이모트 대체. 작은 회색/하늘색 구름 한 덩어리에서 "z" 모양 작은 곡선들이 위로 떠오르는 느낌(글자 z는 작게 표현 OK — 작은 부호로). 부드럽고 졸린 톤.

### 9. `prototypes/mallang-quiz-battle/assets/trophy_gold.png` — 투명, 512x512
1등 트로피. 황금색 컵 모양 트로피 위에 작은 별 하나, 양 옆 손잡이. 살짝 의인화된 작은 눈/미소. 받침대는 옅은 갈색. 빛나는 하이라이트. 색감은 따뜻한 골드(#fbbf24 톤).

1/2/3등 시상대. 가운데 가장 높은 1등 단(금색 별 장식), 왼쪽 2등 단(은색), 오른쪽 3등 단(동색). 캐릭터는 없고 시상대만. 부드러운 파스텔 톤, 단 위에는 작은 별/리본 장식. 그림자 약간.
